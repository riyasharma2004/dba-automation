How to create masked views
Masking examples Run these in psql to protect sensitive data
A masked view shows fake/hidden values to restricted users while the real data stays safe in the original table. Create a view, then give readonly roles access to the view only — not the table.
-- Example: Create masked view for users table CREATE OR REPLACE VIEW users_masked AS SELECT id, left(email, 3) || '***@***.com' AS email, left(full_name, 1) || '***' AS full_name, '***-***-' || right(phone, 4) AS phone, '********' AS password, created_at FROM users; -- Give readonly role access to view only GRANT SELECT ON users_masked TO readonly; -- Revoke direct table access REVOKE SELECT ON users FROM readonly;
