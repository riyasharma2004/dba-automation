 PostgreSQL Setup and Management Project

DBA Automation Project

Overview

This project demonstrates database administration automation using PostgreSQL along with a Flask-based dashboard for monitoring and analysis. It simulates real-world DBA tasks in a production-like environment.

Tech Stack

PostgreSQL
Python (Flask)
SQL
Linux (Ubuntu)
Features

Database Monitoring Dashboard
Slow Query Analysis
Index Usage Tracking
Vacuum Monitoring
Security & Data Masking Insights
Project Structure

app/ → Flask dashboard application
docs/ → Internship phase documentation
screenshots/ → Dashboard outputs
Setup Instructions

Clone the repository

Install dependencies:

pip install -r requirements.txt
Configure PostgreSQL database

Run the application:

python app/app.py
Documentation

Detailed phase-wise work is available in the docs/ folder.
